Model overview

This dashboard simulates a closed-population SIR model and compares its scaled weekly incidence with a small embedded hypothetical influenza-like illness dataset. It is intentionally simple, educational, and fully static for GitHub Pages.

dS/dt = -βSI/N
dI/dt = βSI/N - γI
dR/dt = γI

Interpretation notes

  • Hypothetical only: the observed data are embedded demonstration values, not real CDC surveillance.
  • β is calculated from R₀ and γ using β = R₀ × γ.
  • γ is calculated as 1 / infectious period.
  • ρ is a reporting/scaling multiplier used to compare model incidence to the observed data scale.
  • Effective Rt declines as susceptible people are depleted: Rt = R₀ × S/N.
